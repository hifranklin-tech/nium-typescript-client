# QuoteIntent

Indicates the intended use of the quote.   * `EXECUTABLE`: Quote can be used to create a conversion.   * `INDICATIVE`: Quote is for rate-checking purposes only and cannot be used for conversion. 

## Enum

* `Executable` (value: `'EXECUTABLE'`)

* `Indicative` (value: `'INDICATIVE'`)
